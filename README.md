# obit-cooperative-site

## Mobile design standard

Most Obit users visit on phones. Build and review every site update at narrow widths first (320, 375 and 430 pixels), then tablet and desktop. Keep navigation, forms, pricing, action buttons and status messages usable by touch. Avoid horizontal page overflow, preserve readable text and make wide data tables scroll within their own container. Verify the public page and the membership flow on a phone viewport before deploying.
