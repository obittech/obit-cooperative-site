Obit Billionaires Automation

A private publishing tool operated by Obinna Onuigbo for the Obit Billionaires YouTube channel.

What the application does

The application prepares daily affirmation broadcasts, connects them to the channel's existing live stream and broadcasts prerecorded narration with affirmation cards. It checks the authorized channel before publishing and completes the broadcast after playback.

The recorded guide encourages confidence, discipline, gratitude and purposeful action. It is not an interactive avatar. Content does not promise financial results.

Why Google authorization is needed

The channel owner authorizes access to YouTube channel information, live stream configuration and broadcast metadata so the application can create, bind and complete broadcasts on the owner's behalf. Authorization uses the YouTube API and the youtube.force-ssl permission. The application is for the operator's own channel and is not open for public account registration.

Viewers watch on YouTube and do not sign in to this application or provide Google credentials to it.
